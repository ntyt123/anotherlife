# 1.3.109 人物关系网与历史回溯

## 变化

- 关系图按所选轮结束时的同一历史投影取得人物、姓名、身份和关系。逆序处理根数组、条目、字段级差分，兼容 `_had/_prev/_missing` 和旧 `from`，不再把一个字段的旧字符串当整张关系表。
- 后期新增人物会随时间轴退出；历史删除的条目在有回退依据时恢复。开局已有的亲属不会因为正文未露面而被删掉。
- 改为确定性力导向网图，没有固定的主角坐标、父节点或强制通向主角的线。各人的关系可以互相连接；没有记录的关系不补线。
- 读取既有关系条目的明确主体／对象、角色自己的结构化关系、配偶／子女等引用；兼容档案身份／背景中明确点名的有限亲属和室友称谓。这是只读显示整理，不回写关系，不读取正文猜首次出场，不因同姓、同班或共同出场自动连线。复杂或含糊叙述不作通用语义推断，旧数据未记载的关系不会凭空生成。
- 支持缩放、滚动、鼠标或键盘选择人物、聚焦相邻连线及查看当时关系。当前图可打开唯一匹配的当前档案；历史模式不按历史数组下标打开当前人物，避免串人。
- 关系变化跳转涵盖角色新增和有关关系资料变化。位置缓存只保存坐标，改名和关系标签更新不会残留旧资料；只在关系页构建关系图。

## 旧档与生效

没有改宿主、结算格式、剧情、回退账本或存档文件；不新增RPC或模型请求，不做存档迁移，也不自动重算。客户端热更新或刷新／重新打开界面即可加载，本次改动无需重启宿主。

历史仍受原记录完整程度限制。对于缺少回退依据的旧差分，界面显示历史可能不完整，不把当前值伪装成历史真相。开局若只保存主角与亲属的三条关系，图中就只有这三条线；不会为了外观成网而虚构夫妻或朋友关系。

## 验证范围

新增数据层和界面专项覆盖历史字段／条目／整表、增删逆推、旧格式、姓名和父路径、原型防护、NPC之间关系、同名与歧义、否认／假设、去重、确定性布局、时间轴、缩放、节点选择、历史详情和实际App导航。用导入档副本只读核对：现在71名NPC，开局及下一轮均回到3名；加上主角分别为72／4个节点。当前52条关系中8条连接NPC双方。原始存档不改写。

验证是原客户端React树／处理器的隔离执行和模块检查，不是实际浏览器视觉验收。未调用真实模型，未执行真实游戏回退或重算。
