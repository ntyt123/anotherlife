# 1.3.93：叙事权限与单一文风来源

## 修改范围

- 将真实目标、信息公开、普通言行与重大决定分别处理。允许日常交谈、拒绝、推托、小动作和心理，不通过捏造过去坦白、表格或转述来突破明确保密范围。
- NPC保留独立目标和误判；NPC判断不自动成为旁白事实，不默认低调必然触发更精准的改造任务。后台、人设、摘要继续共用同一事实与权限规则。
- 移除程序内置的修辞次数、固定对白动作比例、感官限定、机械关系速度和固定收尾主体。文风、心理、回望、节拍与停点由实际所选指导、本轮要求和作者手填内容决定。
- 默认写作块只有一个来源：`lib/writing-contract.mjs`，正文和提示词编辑器使用同一默认文本。保留人称与视角占位符；本局人称设置与生成块填充一致。
- 保留用户自定义writer/anti/output/world及作者补充，不静默重置。若自定义内容本身仍有旧限制，日志会标出覆盖块，不能宣称已自动清除。
- 所选指导先占位、模板覆盖后再装入正文，防止其内部同名标题被误认作writer/anti槽位。
- 已有轮次日志新增`[writing-contract]`记录，包含本轮实际读取的指导ID、来源、字符数、SHA256版本摘要及自定义覆盖块；不记录密钥或新增完整指导副本。
- 篇幅保持提示性质，不设置段落配额、不以凑数强推阶段；同步移除工具描述里“字数不足即不合格”的残留要求。

## 不变项

不替用户切换或编辑文风，不修改全局选择、文风库、卡片、世界书和旧存档；不迁移状态结构，不清洗旧剧情；不更改人物资料保护、财务、去重及回滚算法；不增加关键词剧情拦截、审稿模型或额外生成步骤。实际安装版已有独立保护差异通过增量同步保留，不整包覆盖。

## 验证范围

新增16项专项覆盖默认限制移除、信息与授权、叙述者/角色知识区别、自然收束、指导完整注入、即时切换和指纹、自定义保留、人称一致、同名标题保护、真实生成处理器请求与日志。

真实处理器在隔离VM中运行，文件与存档为内存Map，模型为桩。实际原生请求的system独立于messages，测试核对两者与工具描述。正常链路为检索、正文、结算各一次，没有新增审稿调用。

源码相邻基线97项：95通过、1失败、1跳过。修改后113项：111通过、同一项失败、同一项跳过；新增16项全部通过。旧失败为`工具 game_content 只有笔记时失败，不把原标签回填`的错误文案正则不匹配，已在独立修前副本复现，本次不混修。`npm run check`通过，含语法与通用/文风/CP三份界面工厂一致性检查。

实际安装目录基线80项：76通过、3失败、1跳过；修改后96项：92通过、相同3失败与1跳过，新增16项全过。安装缺少部分仓库旧测试，所以两端总数不同，不混报。源码与安装均无新增失败；50个非目标运行文件SHA256不变，安装入口及默认模板原有独立保护差异保留。安装版语法、三工厂一致性和原生入口导入通过（未调用apply）。

这不代表真实模型的阅读效果已验收。没有发起收费模型调用，没有浏览器实机验收，也没有代用户重启DSH。更新已加载的宿主入口后，需要重启实际运行的DSH实例，再用新轮次核对日志及正文效果；旧轮次不会自动改写。
