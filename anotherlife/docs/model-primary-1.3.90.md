# 1.3.90：模型主导，程序辅助

## 本轮范围

按用户确认修改：CP采纳、股东格式兼容、所有模型入口的思考参数；奖励仍以模型的叙事判断为主，程序辅助转换、记账与防重复。不新增个人自动还款，不做专项联网改造，不回填旧局。

### CP

- 不再要求evidence是正文连续原句，不再用关键词、职业措辞或程序对剧情的二次判断否决模型。
- 模型未提交CP结果时不自动凭正文/微博创建；模型明确提交时，按可对应的角色建立或更新。
- 未知人数保持countKnown=false，前端仍显示未知；明确总数优先于增量，避免1800含周增400误变2200。
- 可识别微博来源辅助关联和去重；无法关联的来源仅记为模型引用，不冒认已核微博，也不丢弃正常业务更新。
- 保留开关、角色唯一对应、数值计算、事件去重、逆向差分和回滚。

### 股东

- 明确schema的actorId/name/share字段。
- 接受actorName/姓名及ratio/比例/持股比例，接受明确百分比、全角百分号与单股东对象。
- 等价字段归一，矛盾值指出对应股东；保留总比例与计算边界检查，不凭空转资或重复扣初始余额。

### 奖励

- 兼容completeTask、claimTask、claimReward及常见中文写法，单对象事件也可处理。
- 模型叙事确认不再被依据缺少或旧active状态二次阻断；明确领取叙事任务可同次确认完成与领取。
- 仍按已登记奖励记账；未知任务不凭空发奖，rewardLog及任务领取状态防止重复支付。
- 非模型来源的手动操作不能凭空完成任务。数值型任务仍由程序辅助计算登记目标。

### 思考档

- 新增统一参数模块，覆盖辅助槽和直连模型请求；文风任务独立传递并保存档位。
- 没有单独设置的辅助槽继承正文；已有单独档位和显式模型默认不被覆盖。
- 不写死high，不替换用户所选provider/model，不改变token上限、温度或停止信号。
- 部分保存保留其他槽位；共用设置可被新局与独立文风任务读取。
