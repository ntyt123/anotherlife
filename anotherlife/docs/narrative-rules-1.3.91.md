# 1.3.91：三条跨世界叙事规则

## 范围

- 主角意图与角色判断分开：玩家明确设定优先于模型推测；NPC可误解、劝说、阻挠或强迫，其观点不自动成为旁白真相。仍支持明确设定的自我欺骗、转变与既定世界机制，不保证目标实现。
- 不预设固定成长路线：正常保留训练、控制、复仇等有依据的长期人物目标和具体冲突；不为纠正玩家选择，让不同人物机械执行同一个改造任务。
- 明确设定更正同步资料：区分设定声明与角色台词；通过已有字段、变更依据与差分机制更新对应资料，摘要与检索不把已被纠正的推断重新当真。

## 实现

规则集中在 `lib/narrative-rules.mjs`。正文、人设生成/补全、长期摘要及后台结算引用共用文本；固定规则不依赖用户是否保留旧的可编辑模板。后台常驻规则去重后前置，保留原人设、外貌、职业等既有要求。

主结算的同一次模型请求新增本轮玩家原文，解决“正文没有复述的设定更正无法进入后台”的上下文缺口。对未出场但明确被更正的人物同样核对，并要求在 `chars` 对应条目填写 `固定资料变更依据`。输入里的愿望、计划、承诺和金额不自动变成已经发生的财务事实。

未修改固定资料保护算法、字段归属、差分、回滚、模型选项或存档结构。没有新增语义审稿、剧情关键词拦截、自动删文、额外模型调用或历史迁移。用户存档与卡片/世界书不修改。
