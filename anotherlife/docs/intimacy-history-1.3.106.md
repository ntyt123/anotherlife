# 性经验事件账本 · 1.3.106

主角页新增只读性经验模块：按对象汇总已记录场次、行为类型与次数，展开可看时间、地点和来源轮次。原“经验”文字概述保留。

## 记录口径

- 仅记录事件发生时主角和对象均明确18岁及以上的事实；未知、矛盾或既有对象未确认成年时不记。
- 从启用后的正常结算开始，不扫描旧正文，不根据旧概述推算人生总数。
- 同场多行为分别计次数，但总场次只记一场；多对象同场不翻倍计算总场次。
- 次数未明确时只记事件，保留countKnown=false，不猜精确数。
- 1.3.108 起：已有账本时，模型省略该字段或给 null 视为本轮没有事件，静默保留且不再提示；格式错误、对象不能唯一对应、成年依据不足、重算截断仍如实提示，且提示不再被并进笼统的“资料”一条。
- 新事件使用本轮唯一编号。跨轮续接必须引用已有完整事件id，提交该场行为的累计绝对值；未交付的其他行为类型保留。
- 恋爱身份、计划、梦境、旧事的重复回忆不构成新事件。此类语义由结算模型判断，程序不按正文关键词计数。

## 数据与结算

- 独立保存于protagonist.intimacyHistory；普通人物字段及状态路径不能覆盖此账本。
- 同一次已有结算工具或JSON回复交intimacyEvents；支持顶层及other/diffs/updates完整根包装。没有新增或续接返回[]。
- 原始账本不进入完整变量快照。结算只获得最多16个相关／近期对象摘要和最多8条近期相关事件引用。
- 角色优先按actorId关联；旧人物缺标识时只保留账本内稳定引用，不批量修改NPC。后续取得actorId可桥接，已登记身份不能被同名新角色冒用。
- 重算撤销本轮贡献再重建，重复重算不累加；空数组可撤销本轮贡献，早期记录保留。漏交、坏格式、冲突或截断保留原账和原回退记录。
- 删轮和重新生成沿用原差分回退。角色档案删除不自动抹掉已记录的历史对象名。

## 界面

主角明确成年且处于游玩阶段才展示新模块。模块只读，没有独立生成、编辑、补录或清空按钮。显示“已记录”而非人生总经历；对象卡默认折叠，HTML按普通文字展示。基础信息与弹窗不重复展开原始账本。

## 加载与边界

修改包含宿主入口，需要更新后完整重启DSH，随后在原局继续正常结算。不迁移或改写旧存档，不自动重算旧轮，不新增独立模型调用或付费重试。

本次验证使用虚构成年样本、真实插件处理器与React树、内存文件系统和模型桩；没有调用真实模型、打开真实浏览器或代用户重启。模型是否稳定交付实际事件、页面视觉和真实续玩仍待验证。
