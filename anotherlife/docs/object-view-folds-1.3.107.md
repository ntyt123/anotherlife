# 对象经历与角色列表折叠 · 1.3.107

仅改前端展示，沿用1.3.106的成年事件账本、计数和回退规则；不改宿主、结算提示词或存档。

- 主角页“性经历”整区可折叠，按对象分别列卡片；初次进入时最近对象展开，其他对象收起。

客户端更新或刷新／重新打开界面即可看到新展示，无须为本次前端更新重启宿主或重算变量。真实浏览器视觉和键盘交互尚未现场验收；验证以纯函数、React树与实际插件App树的隔离测试为限。
