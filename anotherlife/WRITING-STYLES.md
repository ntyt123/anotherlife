# 文风提炼与指导库（1.3.79）

入口：**设定 → 写作指导 → 从小说提炼／管理文风**。

## 使用

1. 选 TXT／Markdown 文件，或粘贴原文。默认 UTF-8，也可选 GB18030／GBK。单份原文最大32 MB。
2. 选择已配置的 DSH 服务及模型，提炼不会切换正文主模型，也不向浏览器索要密钥。
3. 填写渠道实际上下文容量和输出预算。默认1000000令牌；填写0可读取模型声明（模型未声明时需手动填写）。输入计数是启发式估算，不是精确分词；预留输出预算和5%余量，至少预留1024令牌。渠道仍可能有更低限制。
4. 点“容量预检”。默认整本原文一次发送，不做摘要、不抽样、不截断。估算超限时自行选择分章、更长容量，或明确确认仍发送全文。预检和查看历史不调用生成模型。
5. 点“开始提炼”。此时才产生模型请求。分章按章节／行边界优先切分，连续覆盖全部原文；综合阶段可能有多层，界面次数为“至少”估算，不是固定费用报价。
6. 完成后点“查看结果”，阅读并修改指导、名称及原文证据。匹配引文仅证明摘录存在，不证明观察结论正确；前中后都有证据也不等于全文理解覆盖率。
7. 保存后回到上方“用哪一份”选择加载。保存、导入、提炼都不自动切换当前指导。

也可“新建指导”直接粘贴已有文风指南，或复制当前指导再修改；支持另存、JSON／TXT导入导出和删除。修改已启用的指导会刷新读取缓存。删除前须先切换到另一份指导。同名新建和旧窗口覆盖均会明确提示。

## 本机与远端迁移

1. 本机在指导预览中点“导出 JSON”或“导出 TXT”，已保存文风和未保存的提炼草稿均可导出。
2. 把文件带到远端，进入同一个设定入口，选择“导入文风 JSON／TXT”。
3. 检查、修改名称与正文，再点“保存”。同名内容不会自动覆盖，需改名另存。
4. 从上方“用哪一份”选择这份指导，才会启用。导入本身不保存、不启用、不调用模型，也不需要传小说或迁移游戏存档。

JSON保留名称、指导正文与提炼依据，格式继续兼容1.3.78导出文件；也接受普通的name＋guide、title＋content等单份JSON对象。导出不携带本机资料编号、路径、凭据或引文核验认证。

TXT是带UTF-8 BOM的纯指导正文，默认名称取文件名，不含提炼依据；标签、空行、缩进和模板变量保留。导入也接受Markdown纯文本、带BOM的UTF-16或GB18030／GBK旧文本。

文风文件上限2 MB，指导正文上限20万字符，区别于小说原文的32 MB；超限或格式错误会明确提示，不截断内容、不覆盖当前编辑。导入引文只作为参考，不继承导出端的“已核验”状态。

## 长任务

- 可停止；失败、截断或停止不作为完整指导自动保存。
- 保留已经完成的原文分析阶段与未完成的原始输出，支持把阶段结果打开为草稿。
- “继续／重试”须再次确认。可调整当前模型与预算，沿用原分批范围；已完成阶段不重新请求。若新预算连原分批也容不下，明确拒绝继续，需提高容量或新建任务。
- 不自动收费重试。重启不自动恢复生成；未完成任务标为中断，由玩家决定是否继续。
- 任务不占用正文游戏的长串行锁，也不通过游戏的停止开关互相取消；最多同时运行两个提炼任务。

## 数据与兼容

所有新增数据在现有插件工作目录，独立于游戏存档：

- `simulator-writing-styles.json`：文风库、原文目录、任务目录与上次提炼配置。
- `simulator-style-source-<id>.json`：独立小说原文及校验信息。
- `simulator-style-task-<id>.json`：阶段结果、进度、最终草稿及失败输出。

原文分块上传后，在宿主拼成一次完整请求；上传分块不等于模型分批。删除指导不会删除原文和任务。JSON导出不包含整本小说、凭据或游戏状态；外部导入的引文不会沿用他处的“已核验”标记。

旧的 Tavern Skill 指导仍可选择。新指导使用 `style:` 编号，只在插件文风库里保存，不创建或修改 Skill 文件。启用时只把指导正文送入现有写作指导位置，不附整本原文和证据，不改人物卡、旧存档、结算规则或通用文风优先级。

## 开发验证

- `npm run build:writing-style`：从独立界面工厂同步到原生客户端。
- `npm run check`：包含工厂一致性与新增模块语法检查。
- `node --experimental-vm-modules --test tests/writing-style.test.mjs tests/writing-style-ui.test.mjs`：纯逻辑、模型桩、实际宿主和界面交互隔离验收。

隔离测试不等于真实浏览器和百万上下文模型验收；这次开发未自动调用收费模型。宿主入口有变更，更新部署后须重启 DSH。
