# 气味文案同步（1.3.82）

## 自动触发

AI气味文案开关开启、主结算有有效结果时，两处计时与强度计算结束后检查本轮出场的成年女性和符合条件的主角。旧档没有同步依据也会触发，无需先点击手动按钮。未出场NPC不因这项功能被整档批量刷新。

文案按强度六档（10、30、50、70、85为边界）、穿着时长档（1、6、12、24、48小时）、衣物名称与材质绑定。跨档、换洗、时长下降、文案改变或依据缺失会重新检查。如果主结算已经提交新文案，而且后台没有再改变对应档位，可直接绑定，不重复调用。不是所有微小数值变化都额外生成一次。

需要刷新时，把本轮需要的条目合并为一次独立的结算模型请求，输入最终数值，不重跑正文或主结算。新增请求会产生模型费用。请求仅含成年人的衣物、材质、强度和小时数据；不含旧气味正文、人物姓名、身体隐私或剧情，生成客观、非色情的衣物状态。

## 失败和手动入口

设定 → 气味由谁写 → AI写 → 同步气味文案。

按钮会调用结算模型，对已有成年角色衣物做一次显式刷新，包括未出场角色，不推进时间或改变强度。同步失败、条目漏回或冲突、回复截断时保留旧文与当前数值，提示失败。已经失败的条目不会随下一轮静默付费重试，可点击按钮重试；主结算后续提交符合最终状态的新文案也可解除失败标记。

这项功能不是文风评分器，绑定状态不代表模型文案在语义上已由程序核验。衣物数据无效、年龄不明、未满18岁或年龄与生日矛盾者不会进入新增同步流程；独立校验年龄，不复用历史引擎门槛。没有修改原引擎阈值、增长速度或句库。

## 保存与回滚

成功记录`_scentTextSync`：来源、对应强度、小时、档位指纹、文案哈希和更新轮次。失败记录最后一次尝试，不把旧文标为最新。

自动同步的文案和元数据进入本轮diff；手动同步附加到最近一轮助手diff。删轮、重生成沿用原回滚机制。安装不会主动读写历史存档，也不会直接迁移导入文件；实际游玩结算或用户点击按钮时才写入。

宿主代码已改变，更新后需完整退出并重启DSH。本地模块/真实处理器/React测试桩通过，不代表真实模型文案或浏览器实机已经验收。
